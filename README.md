# Layout-Aware-Multimodal-Document
An AI-powered LMDI system that extracts, understands, and analyzes information from complex PDF documents, including text, tables, images, and charts. It uses OCR, LLMs, and Retrieval-Augmented Generation (RAG) to provide accurate, context-aware answers with relevant document references. Built using Python, Streamlit, Ollama, and Llama 3.2.
